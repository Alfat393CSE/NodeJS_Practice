## Node.js Practice

This section covers the essential Node.js concepts needed to build a strong foundation in backend development.

### Topics Covered

* Node.js fundamentals and runtime
* Modules and `require` / `module.exports`
* File System (`fs`) operations
* HTTP server and request/response handling
* Synchronous vs. asynchronous operations
* Event Loop and non-blocking I/O
* Callbacks, Promises, and `async/await`
* Working with URLs, query parameters, and form data
* Streams and Buffers
* Error handling
* npm and package management
* Building basic Node.js applications
